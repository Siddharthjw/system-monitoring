# Windows Server Health Monitor - Project

What it does: Monitors server health

- Checks CPU, RAM, Disk, Network (ping) every 5 mins
- Logs to health.log
- Auto-creates tickets in ticket.log if CPU >80% or Disk <10GB

Tech Used: Python, psutil, Task Scheduler
How to Run: python health_check.py
